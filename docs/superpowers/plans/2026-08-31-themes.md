# Themes Implementation Plan

> **For agentic workers:** Execute phase-by-phase. The app must stay `tsc`-clean and test-green after EVERY task. Because static `Colors` stays = Light, unmigrated files keep working — migration is incremental and safe to pause between batches.

**Goal:** A tonal theme system (Light/Midnight/AMOLED/High-Contrast/Warm-Paper/Cool-Slate) selectable at runtime, gated as a Pro perk, persisted across launches.

**Architecture:** `ThemeProvider` + `useTheme()` + `useThemedStyles(makeStyles)`; per-file migration of static `StyleSheet.create` to a `makeStyles(Colors)` factory. See `docs/superpowers/specs/2026-08-31-themes-design.md`.

**Tech:** React Native/Expo, TypeScript, React Context, AsyncStorage.

---

## Phase 1 — Theme infrastructure (no visual change; app stays in Light)

### Task 1.1: Palette type + palettes
**Files:** Modify `lib/theme.ts`.
- Read the current `Colors` object. Define `export type ThemePalette = typeof lightColors;` where `lightColors` is the current `Colors` values (rename the literal to `lightColors`).
- Define `export const palettes` mapping theme name → palette. Start with **light**, **midnight**, **amoled** (dark themes: invert background/surface/text scales, keep `accent`/`accentGlow` identical; borders/overlays become light-on-dark). High-Contrast / Warm-Paper / Cool-Slate can be added in Task 1.1b once the 3 core palettes are verified rendering.
- Keep `export const Colors = lightColors;` so every existing import still resolves to Light.
- Export `export type ThemeName = keyof typeof palettes;` and `export const THEME_META: Record<ThemeName, { label: string; pro: boolean }>` (light/midnight = `pro:false`; the rest `pro:true`).
- Verify: `npx tsc --noEmit` clean; `npm test` green (no behavior change yet).
- Commit.

### Task 1.2: ThemeProvider + hooks
**Files:** Create `lib/ThemeContext.tsx`. Test `__tests__/ui/ThemeContext.test.tsx`.
- `ThemeContext` provides `{ name: ThemeName; colors: ThemePalette; setTheme(name): Promise<void>; ready: boolean }`.
- On mount, read `@quorum/theme` from AsyncStorage; if a valid ThemeName, set it; else keep `light`. Set `ready=true` after.
- `setTheme(name)`: sets state + persists to AsyncStorage. (Pro-gating enforced at the call site / picker, not here — but ignore unknown names.)
- `export function useTheme(): ThemePalette` → the active `colors` (falls back to `lightColors` if used outside a provider, so tests/unmigrated render safely).
- `export function useThemedStyles<T>(make: (c: ThemePalette) => T): T` → `const c = useTheme(); return useMemo(() => make(c), [c]);`
- Tests: provider defaults to light; `setTheme('midnight')` updates `useTheme()`; persists (mock AsyncStorage) and restores on remount.
- `tsc` + tests green. Commit.

### Task 1.3: Wrap the app + prove it switches
**Files:** Modify `app/_layout.tsx` (wrap the tree in `<ThemeProvider>`). Temporarily add a hidden/dev theme toggle OR wire the real picker in Phase 3 — for Phase 1, just wrapping is enough (default Light; no visual change).
- Verify app still builds, `tsc` clean, tests green. Commit.

## Phase 2 — Migrate files to the themed pattern (batched)

Apply the **migration pattern** (spec §"The migration pattern") to every file that
uses `Colors` in a `StyleSheet.create`. After EACH batch: `npx tsc --noEmit`
clean + `npm test` green + commit. Batches (adjust to real file list via
`grep -rl "lib/theme" app components`):

- **Task 2.1** — shared components batch A: `components/*.tsx` (GlassCard, Toast, ConfettiParticles, QuorumProgressBar, AnimatedButton, PaywallModal, PlanBanner, MomentsGallery, OnboardingSlider, ContextSheet, SOSModal, TemplatesModal, etc.).
- **Task 2.2** — `components/home/*` and `components/plan-detail/*` and `components/create-plan/*`.
- **Task 2.3** — tabs: `app/(tabs)/index.tsx`, `discover.tsx`, `activity.tsx`, `profile.tsx`, `_layout.tsx`.
- **Task 2.4** — modals/screens: `app/plan-detail.tsx`, `app/create-plan.tsx`, `app/chat.tsx`, `app/social.tsx`, `app/settings.tsx`, `app/user-profile.tsx`.
- **Task 2.5** — auth + misc: `app/(auth)/login.tsx`, `app/join/[code].tsx`, `app/_layout.tsx` (SplashScreen styles), any remaining.

**Per-file checklist (from spec):** wrap stylesheet in `makeStyles = (Colors: ThemePalette) => StyleSheet.create({...})`; add `const Colors = useTheme();` + `const styles = useThemedStyles(makeStyles);` in the component; drop `Colors` from the theme import (keep Fonts/FontSize/Radius/Spacing); relocate any module-scope `Colors.*` constant into `makeStyles`/the component; report any that can't move cleanly.

**Note:** files with multiple components each needing themed styles — give each its own `makeStyles`/`useThemedStyles`, or one shared factory used by all.
