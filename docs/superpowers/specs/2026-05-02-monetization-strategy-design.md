# Quorum Monetization Strategy

**Date:** 2026-05-02  
**Status:** Approved  
**Scope:** Full monetization roadmap across 3 phases

---

## Context

Quorum is a pre-launch social event planning app built around a "quorum" mechanic — plans confirm when enough people vote yes. The core differentiator is the experience *around* the event: chat, moments (post-event photos), and safety features. The viral growth loop depends on joining and voting remaining completely frictionless.

The strategy below is designed to preserve that loop while building sustainable revenue.

---

## Core Principles

1. **Safety is never paywalled** — Safety timer, SOS, emergency contacts, scam detection, and any future safety features are always free. No exceptions.
2. **Joining is always free** — Voting, joining plans, discovery, and the friend system are always free.
3. **Limits target power users, not casual users** — Free tier limits are generous enough that a casual user (1–2 plans/month) never hits them. Limits are volume-based, not feature-based.
4. **Monetization enhances experience, it does not restrict core functionality.**

---

## Phase 1 — Subscription (Launch)

### Free Tier (Forever)

| Feature | Limit |
|---|---|
| Active plans (created) | 3 at a time |
| Moments photos per plan | 10 |
| Chat history | 30 days |
| Saved plan templates | 2 |
| Cover photos | Standard library only |
| Plan joining / voting | Unlimited |
| Friend system | Unlimited |
| Discover / search | Unlimited |
| Safety timer + SOS | Always free |

### Quorum Pro — ~$5.99/mo or ~$44.99/yr

| Feature | Pro |
|---|---|
| Active plans | Unlimited |
| Moments photos per plan | Unlimited + HD quality |
| Chat history | Full history |
| Saved plan templates | Unlimited + custom templates |
| Cover photos | Custom uploads + themes |
| Plan analytics | Vote trends, engagement stats |
| Support | Priority |
| New features | Early access |

**Upgrade trigger:** Power users — frequent plan creators, groups that take lots of moments, organizers saving multiple templates — hit limits naturally after they've already found value in the app. The ask to upgrade comes at the right moment.

---

## Phase 2 — Creator Tools (~6–12 months post-launch)

Targets recurring organizers: event hosts, community managers, sports league admins, nightlife promoters. These users treat Quorum as a lightweight event platform.

### Quorum Creator — ~$12.99/mo (standalone tier, includes all Pro features)

- **Promoted plans** — boosted visibility in Discover for a configurable duration
- **Branded plan pages** — custom organizer name, logo, and links on plan cards
- **Waitlist management** — auto-queue when `maxParticipants` is reached
- **Recurring plans** — "every Friday night" auto-generates the next plan on confirmation
- **RSVP export** — CSV download of participant list
- **Advanced polls** — ranked choice voting, hard deadline enforcement
- **Verified organizer badge** — displayed on Creator profile and plan cards

---

## Phase 3 — B2B / Venue Partnerships (~12–24 months post-launch)

Targets venues and brands who want access to the organizer audience built in Phase 2.

- **Venue listings** — venues pay to appear as suggested locations when a nearby plan is being created
- **Sponsored plans** — brands co-sponsor public plans that appear natively in Discover (contextual, not banner ads)
- **White-label plans** — venues create their own branded plans (club night, pop-up) that appear as native Discover content

All B2B placements are contextual — no intrusive ad units that degrade the user experience.

|---|---|---|---|
| 1 | Quorum Pro subscription | Power users / frequent creators | Launch |
| 2 | Quorum Creator tier | Event organizers / community managers | 6–12 months |

## What Is Never Monetized

- Safety timer and SOS
- Emergency contact features
- Scam detection warnings
- Location sharing for safety
- Voting and plan joining
- Basic chat (with history limit on free)
- Friend system and discovery
